# Kozmik Tembellik Ölçme Cihazı

## Resmi Duyuru

Bu depo, insanlığın en önemli sorunlarından biri olan **tembellik** konusunu bilimsel (değil), resmi (gibi) ve son derece abartılı bir şekilde ele alan dünyanın ilk ve tek Kozmik Tembellik Ölçme Cihazı'nı barındırmaktadır.

Kullanmadan önce lütfen şunları yapın:
- Hiçbir şey yapmayın.
- Bir kahve alın (etkisiz olsun).
- Telefonunuzu kontrol edin (gereksiz yere).
- Sonra da bu kodu çalıştırın.

## Neden Bu Proje Var?

Çünkü var olması gerekiyordu. Evren tembellik üzerine kuruludur. Bu cihaz o gerçeği ölçer, raporlar ve size "Profesyonel Tembel" unvanı verir.

Hiçbir bilimsel geçerliliği yoktur. Ama **zorunludur**.

## Kurulum

```bash
# Python 3 yüklü olsun yeter. Başka bir şey yüklemeyin, tembellik bozulur.
python tembellik_olcucu.py
```

## Özellikler

- Abartılı yükleme animasyonu (gerçek zamanlı tembellik hissi)
- 4 kritik soru ile tembellik analizi
- Kozmik faktör içeren matematiksel formül (π ve 7.77 kullanır)
- Resmi rapor çıktısı
- İtiraz edilemez sonuçlar
- Gizli notlar (kaynak koduna bakın, ama bakmayın)

## Uyarılar

- Bu cihaz sizi daha tembel yapabilir.
- Sonuçlara itiraz etmek yasaktır.
- Cihaz kapanınca siz de kapanabilirsiniz.
- Hiçbir sorumluluk kabul edilmez. Zaten tembeliz.
